# what we need for it
1. a syntax for how it needs to be
2. a parser in javascript to read the file
3. a transpiler to convert the parsed tars to AI python
4. and a js webpage to run that python (additional)

# some features basically first draft
- comments that start with :)
- model	Define a new model
- from	Backend or source
- input / output	Define I/O for the model
- train	Begin training
- evaluate	Run validation/testing
- save / load	Persistent checkpoints
- deploy	Serve model
- predict	Inference command
- custom {}	Advanced options (loss, optimizer, etc.) // could ignore this, as we can embed this in the definition of the ai construction
